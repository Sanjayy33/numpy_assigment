# Numpy Assigments 

<h2>How to run</h2>
<p>
  1. first install python in your system.
  2. create folder.
  3. inside folder create virtual environment.
  (in cmd run command : python -m venv venv)
  4. activate venv (in cmd : venv\scripts\activate (for windows))
  5. install numpy (in active venv run command : pip install numpy)
  6. copy code or create clone of this folder. (git clone #url)
  7. in cmd run this cmd : python file_name.py
  8. you can see output or result of code.
</p>

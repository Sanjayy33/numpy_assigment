# Numpy Assigments 

<h2>How to run</h2>
<p>
  1. first install python in your system.<br>
  2. create folder.<br>
  3. inside folder create virtual environment.<br>
  (in cmd run command : python -m venv venv)<br>
  4. activate venv (in cmd : venv\scripts\activate (for windows))<br>
  5. install numpy (in active venv run command : pip install numpy)<br>
  6. copy code or create clone of this folder. (git clone #url)<br>
  7. in cmd run this cmd : python file_name.py<br>
  8. you can see output or result of code.<br>
</p>
